## 📌 프로젝트 소개

**온민원**은 일반 사용자와 관리자가 하나의 서비스 안에서  
민원을 접수하고, 처리하고, 현황을 확인할 수 있도록 만든 **스마트 민원 관리 서비스**입니다.

일반 사용자는 민원을 간편하게 작성하고 자신이 접수한 민원을 조회할 수 있으며,  
서비스 내에서 **전체 민원 수**, **전체 민원 처리율**, **평균 처리 시간**을 확인할 수 있습니다.

또한 민원은 아래 카테고리로 나뉘며,  
각 카테고리별 민원 현황을 **실시간으로 확인**할 수 있습니다.

- 환경/청소
- 시설물파손/관리
- 교통/주정차
- 안전/위험
- 생활불편
- 기타/행정

민원 작성 시에는 **이름, 전화번호, 민원 발생 지역, 현장 사진, 민원 내용**을 입력할 수 있고,  
**AI가 사진을 분석하여 민원 내용을 보완하거나 완성**해주는 기능도 제공합니다.

관리자는 접수된 민원을 확인하고 처리 상태를 변경할 수 있으며,  
**미처리 민원만 별도로 조회**, **댓글 작성**, **민원 반려**까지 가능합니다.  
또한 **AI가 민원 내용을 요약**하여 보다 빠르고 효율적인 업무 처리를 지원합니다.

## 🧩 핵심 서비스 설명

### 1. 간편한 민원 접수
일반 사용자는 필요한 항목을 입력하여 쉽고 빠르게 민원을 등록할 수 있습니다.

**민원 작성 항목**
- 이름
- 전화번호
- 민원 발생 지역
- 현장 사진
- 민원 내용

### 2. AI 기반 민원 작성 보조
사용자가 현장 사진을 업로드하면  
AI가 사진을 분석하여 민원 내용을 자동으로 보완하거나 작성에 도움을 줄 수 있습니다.

### 3. 실시간 민원 현황 확인
사용자는 전체 민원 통계뿐 아니라  
카테고리별 민원 현황도 실시간으로 확인할 수 있습니다.

### 4. 민원 처리 과정의 투명성
사용자는 자신이 작성한 민원이 현재 어떤 단계에 있는지 확인할 수 있어  
처리 과정을 명확하게 파악할 수 있습니다.

### 5. 관리자 중심의 효율적인 처리
관리자는 접수된 민원을 빠르게 확인하고  
상태를 변경하거나 댓글을 남기고, 필요 시 반려 처리할 수 있습니다.  
AI 요약 기능을 통해 긴 민원 내용도 빠르게 파악할 수 있습니다.

## 🔄 민원 처리 상태

온민원은 민원 처리 과정을 다음의 **4단계**로 관리합니다.

| 처리 상태 | 설명 |
|------|------|
| 민원 접수 | 사용자가 민원을 등록한 상태 |
| 담당자 확인 및 배정 | 관리자가 민원을 확인하고 담당자를 배정하는 단계 |
| 처리중 | 실제 조치가 진행 중인 상태 |
| 처리완료 | 민원 처리가 완료된 상태 |
